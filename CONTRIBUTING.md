# Zgłoszenia i poprawki

Możesz skopiować kod, utworzyć fork, zgłosić issue lub zaproponować pull request.
Fork nie daje dostępu do sekretów ani Drive autora. Uruchamiaj go ze swoim kontem
i własną konfiguracją. Autor przegląda poprawki przed ich scaleniem.

Przed PR uruchom kontrole opisane w README. Dodaj test zachowania dla zmiany
logiki programu. Nie dołączaj wyników produkcyjnych, poświadczeń ani danych
osobowych. Zachowaj informacje o licencjach materiałów zewnętrznych.
